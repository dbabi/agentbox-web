# Snib art

`favicon-16.png`, `favicon-32.png` and `social-preview.png` here, and the grids in `../content/snib/`, are copies of
the agentbox mascot files. The source, the style guide and the build scripts live in
[dbabi/agentbox/mascot](https://github.com/dbabi/agentbox/tree/main/mascot). Change the art there, then copy it here.
